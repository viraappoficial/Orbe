# ORBE

Selo e comunidade de live sessions de DJs. Site em Next.js + Supabase, hospedado na Vercel.

## Rodar local
```bash
npm install
cp .env.example .env.local   # preencha as chaves do Supabase
npm run dev
```

## Banco
Rode `supabase/schema.sql` no SQL Editor do Supabase.

## Conteúdo
Sessions e links das redes: `src/data/sessions.ts`.
